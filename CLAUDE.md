# Writing skills

Two writing skills are installed in `.claude/skills/`. Use them automatically, without being asked.

- `work-humanizer`: use for any work writing I draft or edit for the user where wording matters: emails, letters (including legal, HR and complaint letters), replies, reports, posts, release notes, landing pages. If the draft is thin and only the writer knows the missing facts, use its interview mode and ask the short questions first.
- `humanizer`: use as a second pass on any longer prose I write or edit, to remove AI-sounding patterns.

Rules that always apply:
- Never change facts, dates, amounts, names, commitments or how certain a claim is. Never invent details.
- For legal or formal documents, keep the legal wording and structure. Only remove AI tells.
- Do not run these skills on code, data, or text the user asked me to leave as it is.
